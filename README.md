# Rémanence — Next.js

Projet indépendant utilisant Next.js App Router, React et TypeScript.

```bash
npm ci
npm run dev
```

Ouvrir [localhost:3002](http://localhost:3002).

```bash
npm run typecheck
npm run build
npm run start
```

[Documentation Next.js](https://nextjs.org/docs/app/getting-started/installation)
